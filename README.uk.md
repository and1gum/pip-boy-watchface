# Циферблат Pip-Boy

Зелена приладова панель для Wear OS на Watch Face Format 3. Великий цифровий час оточують компасний лімб і аналогові стрілки. На екрані також є погода, кроки, пульс, заряд годинника й телефона, атмосферний тиск, схід і захід сонця. Найближча подія календаря йде верхньою дугою.

**Стан:** експериментальний проєкт із вихідним кодом, версія 0.2.0. Перевірено на Galaxy Watch SM-L715F з Wear OS 7 (Android 17), екран 498 × 498. Публікації в Play Store немає. Плавність компаса й вплив на батарею ще потребують тривалого тестування.

## Що потрібно

- Годинник Wear OS з Android 15 або новішим (SDK 35+). Підтверджено роботу лише на пристрої, зазначеному вище.
- Комп’ютер з Android Debug Bridge (ADB) і мережевим доступом до годинника для встановлення APK.
- Два APK з цього репозиторію: циферблат і застосунок-компаньйон. Застосунок на телефоні не потрібен.

Компаньйон надає ускладнення компаса, тиску, сходу й заходу сонця. Решту даних дають система годинника та встановлені провайдери. Для заряду телефона потрібен сумісний провайдер **RANGED_VALUE** — у комплекті його немає.

## Установлення

Виконай [покрокову інструкцію](docs/install.uk.md): збери обидва APK через `bash scripts/build.sh`, спаруй ADB з годинником, установи спочатку компаньйон, потім циферблат і вибери **Pip-Boy** у списку циферблатів. У редакторі признач джерела календаря, заряду телефона, компаса, барометра, сходу й заходу сонця. Один раз відкрий **Pip-Boy Compass**, щоб запустити датчик. Для сонячних подій надай компаньйону приблизне місце та дозвіл на фонове місце, потім відкрий екран із часом сходу й заходу для отримання координат годинника.

У репозиторії немає готового release-APK або сторінки магазину. `scripts/build.sh` створює debug-APK з підписом твоєї машини. APK, зібраний іншим розробником, може не встановитися поверх твоєї збірки.

## Як працює циферблат

Компас читає датчик обертання годинника. Він може зникати, коли дисплей згасає, блокується або дані датчика застарівають. У режимі AOD залишаються час, погода, тиск і час сонячних подій. Доступність погоди й календаря залежить від системних провайдерів та їхніх дозволів. Для сходу й заходу використовується приблизне місце годинника, для тиску — його датчик. За відсутності значення циферблат не підставляє вигадане число.

Проєкт сам не надсилає дані в мережу. Координати й історія тиску залишаються в локальному сховищі компаньйона; циферблат отримує значення через ускладнення Wear OS. Дозволи Android пояснені в [інструкції](docs/install.uk.md#дозволи-й-приватність).

## Для розробників

`scripts/generate.py` створює WFF-файли в `watchface/`; код компаньйона лежить у `compass/`. `scripts/render.py` створює прев’ю з тестовими значеннями. `scripts/build.sh` запускає генерацію, Python-тести, Android unit-тести, lint і складання APK. Потрібні JDK 17+, Android SDK platform 36 та build-tools 35.0.0, Python 3 з Pillow і Node.js для прев’ю/тестових інструментів. Якщо інструменти лежать поза локальним типовим шляхом скрипта, задай `JAVA_HOME` та `ANDROID_HOME`.

```bash
python3 -m pip install Pillow
bash scripts/build.sh
```

Результати: `artifacts/PipBoy-0.2.0-debug.apk`, `artifacts/PipBoy-Compass-0.2.0-debug.apk`, `artifacts/SHA256SUMS`. У Git потрапляють код і документація; `artifacts/` залишається локально. Початковий дизайн — у `pip-boy-watchface-handoff/`, ліцензії сторонніх шрифтів — у `licenses/`.
