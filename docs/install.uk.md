# Як установити Pip-Boy на годинник

Ця інструкція встановлює поточну **debug-збірку 0.2.0** із коду. Її перевірено на Samsung Galaxy Watch Ultra2 (2026; модель SM-L715F) з Wear OS 7. На іншому годиннику назви меню можуть відрізнятися. Потрібні комп’ютер, годинник і мережевий зв’язок між ними; комп’ютер може бути під’єднаний через Ethernet.

[English](install.md) · [Усунення проблем](troubleshooting.uk.md)

## 1. Збери два APK

Установи JDK 17 або новіший, Android SDK platform 36 та build-tools 35.0.0, Python 3 з Pillow і Node.js. Задай `JAVA_HOME` та `ANDROID_HOME`, тоді в корені репозиторію виконай:

```bash
python3 -m pip install Pillow
bash scripts/build.sh
```

Скрипт запускає тести та збирає обидва модулі. Результат — `artifacts/PipBoy-Compass-0.2.0-debug.apk` і `artifacts/PipBoy-0.2.0-debug.apk`. Контрольні суми — у `artifacts/SHA256SUMS`; перевірка: `cd artifacts && sha256sum -c SHA256SUMS`.

## 2. Спаруй бездротовий ADB

На годиннику ввімкни **Параметри розробника** та **Бездротове налагодження**. Відкрий **Спарувати пристрій за кодом**, запиши IP-адресу, **порт парування** й код. На комп’ютері:

```bash
adb pair WATCH_IP:PAIR_PORT
```

Введи код із годинника. Повернися на головний екран бездротового налагодження й подивися **порт підключення**. Зазвичай він інший і може змінитися:

```bash
adb connect WATCH_IP:CONNECT_PORT
adb devices
```

У `adb devices` має з’явитися годинник. Заміни слова `WATCH_IP`, `PAIR_PORT`, `CONNECT_PORT` на фактичні значення. Якщо в WSL використовуєш Windows ADB, запускай `adb.exe`, а шляхи до APK перетворюй через `wslpath -w`.

## 3. Установи й вибери циферблат

Спочатку встанови компаньйон, потім циферблат:

```bash
adb -s WATCH_IP:CONNECT_PORT install -r artifacts/PipBoy-Compass-0.2.0-debug.apk
adb -s WATCH_IP:CONNECT_PORT install -r artifacts/PipBoy-0.2.0-debug.apk
```

Обидві команди мають повернути `Success`. У списку циферблатів годинника вибери **Pip-Boy**. Якщо він не з’явився одразу, відкрий список знову.

## 4. Перевір джерела даних

Джерела даних уже задані; окремого файлу з налаштуваннями не потрібно. Якщо компаньйон та Phone Battery Complication встановлені до вибору циферблата, Wear OS має підставити їх автоматично. Перевір редактор **Налаштувати / Редагувати** лише якщо якесь поле порожнє або було змінене раніше. Задані джерела:

| Ділянка | Джерело | Тип значення |
| --- | --- | --- |
| Верхня дуга календаря | Системна найближча подія | LONG_TEXT |
| Заряд телефона | [Phone Battery Complication](https://play.google.com/store/apps/details?id=com.weartools.phonebattcomp&hl=en) | RANGED_VALUE |
| Лімб компаса | Pip-Boy Compass | RANGED_VALUE |
| Тиск | Pip-Boy Barometer | RANGED_VALUE |
| Схід і захід сонця | Pip-Boy Sunrise and Sunset | SHORT_TEXT |

Одне сонячне джерело призначається в обидва слоти. Погода, кроки, пульс і заряд годинника надходять із системи; їхня доступність залежить від провайдерів і дозволів. Провайдер заряду телефона **не входить у комплект**: спочатку встанови застосунки за посиланням на телефон і годинник. Якщо не користуєшся ним, залиш цей слот порожнім.

Після вибору компаса один раз відкрий **Pip-Boy Compass** у списку застосунків годинника. Надалі він автоматично запускається після перезавантаження годинника чи оновлення компаньйона, якщо відстеження увімкнене, а слот компаса призначений. Кнопка **Stop compass / Enable compass** вимикає або вмикає відстеження. Датчик призупиняється, коли екран згас, перейшов у AOD або заблокований; після розблокування відновлення може тривати до десяти секунд. Пробудження підняттям руки також підтримується. Компас показує магнітний напрямок; він може відрізнятися від географічної півночі.

Для сходу й заходу ввімкни місцезнаходження годинника, надай компаньйону приблизне місце та фоновий дозвіл **Дозволяти завжди**, потім торкнися часу сходу або заходу на циферблаті. Відкриється екран отримання координат годинника; за потреби натисни **Оновити місце**. Якщо свіжих координат немає, застосунок може використати останні збережені або не показати час.

## Дозволи й приватність

APK циферблата не запитує дозволів Android під час роботи. Компаньйон запитує дозволи foreground service для компаса на активному розблокованому екрані, дозвіл на запуск після перезавантаження, а також приблизне й фонове місце для періодичного оновлення сходу/заходу. Android може показувати окремі запити для дозволів під час роботи. Компаньйон не запитує дозволу на сповіщення, тому сповіщення сервісу компаса не з'являється у списку сповіщень, зокрема після встановлення з нуля. Android усе ще може показувати сервіс серед активних програм.

Компас, тиск і місце зчитуються на годиннику. Компаньйон зберігає останні координати й коротку історію тиску локально. У проєкту немає акаунта, аналітики чи власного сервера. Системні провайдери місця та погоди можуть користуватися своїми мережевими сервісами за власними налаштуваннями. Код доступний у цьому репозиторії для перевірки.

## Оновлення й допомога

Для оновлення збери APK з потрібної версії коду й повтори дві команди `install -r`. Використовуй той самий ключ підпису, щоб зберегти налаштування. Старіші APK у [GitHub Releases](https://github.com/and1gum/pip-boy-watchface/releases) — контрольні збірки для відновлення; їхня поведінка може відрізнятися від поточного коду.

Якщо немає погоди, компаса, календаря чи заряду, скористайся [усуненням проблем](troubleshooting.uk.md). Для запису проблеми з компасом є [необов’язкова діагностика](companion-diagnostics.uk.md).
