# Необов’язкова діагностика компаньйона

Після встановлення або перезапуску процесу діагностика вимкнена. Відкрий
Pip-Boy Compass, натисни **Start diagnostics**, повернися до циферблата й
відтвори проблему. **Stop diagnostics** зупиняє збір, зберігаючи запис для
експорту; новий запуск замінює його.

Запис обмежений 1 024 подіями й 15 хвилинами; ліміт перевіряється під час
виконання застосунку. Він не додає таймерів, датчиків або wake lock.
Дані лишаються в пам’яті, тому завершення процесу їх втрачає.

**Export diagnostics** зберігає приватний файл `files/diagnostics.json`.
Для поточної debug-збірки його можна отримати через підключений ADB:

```sh
adb -s WATCH_IP:CONNECT_PORT shell run-as ua.and1gum.pipboy.compass cat files/diagnostics.json > diagnostics.json
```

Запис містить часові мітки, переходи станів і лічильники; координат, календаря
та повного системного журналу в ньому немає. `dataAccepted` означає успішне
повернення виклику провайдера, а не підтверджене малювання на екрані.
Пауза в журналі сама по собі не доводить заморожування Samsung.

Для звичайного користування залиш діагностику вимкненою. Після зупинки старий
обмежений запис залишається доступним для експорту до нового сеансу або
перезапуску процесу. Для порівняння батареї також відключи ADB і налагоджувач.
Плавність і частоту компаса в першій фазі оптимізації збережено; реальну
економію батареї ще не виміряно.
